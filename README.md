## The Wild Oasis - Cabin Management System

## Project Screenshot

![The Wild Oasis Screenshot](/public/screenshot.png)

Wild Oasis is a Single Page Application (SPA) designed for the internal management of a fictional vacation rental Company. This system allows hotel employees to manage cabins, bookings, guest information and staff members seamlessly. Built with **React**, **TailwindCss** and **Supabase**, it offers real-time updates, dark mode, and a smooth user experience.

### ✨ Features

- **User Authentication**: Secure access for hotel employees only.
- **Profile Management**: Employees can upload avatars and change their passwords.
- **Dashboard**: Visual summary of recent stats, bookings, and sales.
- **Cabin Management**: Create, update, or delete cabin records.
- **Booking Management**: Check guests in and out, update booking statuses.
- **Real-time Data**: Automatic updates for cabins and bookings using Supabase.
- **Charts**: Visual data for sales, occupancy rates, and more.
- **Dark Mode**: Fully functional dark mode.

### 🛠️ Technologies Used

**React**: For building the user interface.
**Supabase** - Real-time database and backend.
**Tanstack/React-Query**: For managing and caching API requests.
**React Router**: For handling routing in the SPA.
**Styled-Components**: For styling components.
**Recharts** - Data visualization library for rendering charts.
**Vite** - Fast build tool for modern web projects.
**Netlify**: For deploying the project.

### 🚀 Getting Started

To run the project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/CodeWithAlamin/The-Wild-Oasis.git
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Set up environment variables (check `.env.example` for reference).
4. Run the development server:

   ```bash
   npm run dev
   ```

5. Visit [http://localhost:3000](http://localhost:3000) to view the app.
